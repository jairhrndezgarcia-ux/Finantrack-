# FinanTrack

Gestor web de finanzas personales — Proyecto de Fundamentos de Desarrollo Web (UASLP).

## Tecnologías
- HTML5, CSS3, JavaScript (vanilla)
- PHP + MySQL (mysqli)

## Ejecución local
1. Copiar la carpeta en `htdocs` de XAMPP.
2. Importar la base de datos `finantrack` en phpMyAdmin.
3. Abrir `http://localhost/finantrack/`.
